# README screenshot provenance

The images in this directory are deterministic captures of the real
DesktopLab interface. They are generated by
`apps/desktop/tests/product/readme-showcase.spec.ts` against the local control
plane with explicit test controls enabled.

- The workspace and task content are synthetic and contain no personal data.
- The UI is rendered from repository source; it is not an AI-generated mockup.
- The capture excludes the window command row so absolute local filesystem
  paths are not published.
- The capture test exercises approval, agent evidence, repository inspection
  and an actual local test command before it writes the images.

Regenerate the set with:

```sh
DESKTOPLAB_KEEP_TEST_ARTIFACTS=1 npm --prefix apps/desktop run smoke -- \
  tests/product/readme-showcase.spec.ts --project=desktop --workers=1
```
